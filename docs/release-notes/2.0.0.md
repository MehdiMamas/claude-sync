## claude-sync 2.0.0

2.0.0 is a full rebuild of claude-sync. It is faster and lighter, and it has the same features as 0.1.x: sign-in, groups, the shared `CLAUDE.md`, settings, skills, agents, commands and plugin marketplaces, jobs, personal memory, and the command line.

### Servers with the systemd service

After `claude-sync-cli update`, run:

```
systemctl --user restart claude-sync
```

Until you do, the old daemon keeps running. The new one then takes over and imports your old settings once.

### Installs that are signed out

An install of 0.1.x that is signed out sees the update once you sign in again.

### Going back

Downgrading is one-way: the new version keeps its data in a new file and does not write back to the old format. Your 0.1.x files are kept untouched, so an older version still starts from them as they were before the update.
