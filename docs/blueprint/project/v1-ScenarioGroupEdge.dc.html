Create a group, invite, join: edge cases

Created 2026-11-26. Updated 2026-11-26.

As a host, I want to see what happens when it goes wrong while I create a group and invite a friend, so that my friends get my shared Claude setup even then. Click a step to open its screen. See the flow that leads here.

  1. Create private repo + claude-sync.json
    System: engine.create_group (crates/core/src/engine.rs:639) creates the repo on the host account with the topic claude-sync-group.
  2. Not the host: "Only the host can change"
    System: Error::HostOnly is returned for any change by a non-host (engine.rs:1324). The member screen has no edit controls.
  3. Frame: Groups: sync error
    System: sync error toast (built from the app code, not captured).
  4. Frame: Groups: accept failed
    System: accept error toast (built from the app code, not captured).
  5. Frame: Groups: join failed
    System: join error toast (built from the app code, not captured).
