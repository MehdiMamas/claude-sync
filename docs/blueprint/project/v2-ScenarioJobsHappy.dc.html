Scheduled jobs (accept, run): happy path

Status: current. Created 2026-11-26. Updated 2026-11-26.

As a group member, I want to accept a scheduled job before it runs, so that nothing runs on my computer without my yes. Click a step to open its screen. See the flow that leads here.

  1. schedules.json in the group repo
    System: Repo only, never placed in ~/.claude (docs/architecture.md section 17).
  2. Validate every job
    System: parse_file (crates/core/src/jobs/mod.rs:264): id regex (:161), 5-field cron, args allowlist (:122), 1-240 min timeout, at most 20 jobs.
  3. Show job, ask Accept
    System: Consent is a SHA-256 over cron, prompt, cwd, permissionMode, timeout and args (consent_hash, mod.rs:67).
  4. Reconcile: register accepted jobs
    System: Runs after every sync; Scheduler registers the OS task (jobs/ Scheduler).
  5. OS runs claude-sync run-job
    System: The app binary handles run-job before Tauri starts (app/src-tauri/src/jobs.rs, run_job_main).
  6. Take the job lock
    System: run::lock refuses a second run; a lock older than timeout + grace is stale (run.rs:80, 85).
  7. Run claude -p, keep output
    System: Killed with its tree at the timeout; output rotated (run.rs:117, 151).
