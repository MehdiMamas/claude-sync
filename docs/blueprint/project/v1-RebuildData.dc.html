15Personal repo layoutPrivate repo <login>/claude-sync-personal, no group topic. claude-sync-personal.json {format:1,newDevicesJoin:true}, devices.json {devices:[{id,name,os,lastSeenUnix}]}, README.md, CLAUDE.md (the person’s text outside the managed block), memory/<key>/** (from ~/.claude/projects/<folder>/memory/**), state/** (from ~/.claude/personal-state/**), settings.json (a filtered view). 16TokensNot in a file. OS keychain: Windows Credential Manager, macOS Keychain, Linux Secret Service (GNOME Keyring or KWallet must run). Holds access and refresh tokens per login. Service name "claude-sync". Two layouts a new build must read: the bare access token string (0.1.1 and earlier, and non-expiring tokens), and JSON {access_token, refresh_token, expires_at, refresh_token_expires_at}. A GitHub token never starts with "{", which tells them apart. Tokens are never in files or logs.No Secret Service on Linux means the sign-in lives only in memory.crates/core/src/github.rs:230-238; crates/core/Cargo.toml:23-35; docs/architecture.md:364; github/session.rs:73-91
