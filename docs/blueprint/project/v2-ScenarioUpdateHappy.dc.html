App update through the relay: happy path

Status: current. Created 2026-11-26. Updated 2026-11-26.

As a user, I want to get the new version of the app, so that I run the fixed version without reinstalling. Click a step to open its screen. See the flow that leads here.

  1. Check at start and every 6 h
    System: update_loop in app/src-tauri/src/background.rs; check at app/src-tauri/src/updates.rs:117.
  2. Relay: is a newer release published?
    System: The handler compares the caller version with the latest published release (relay/api/update.ts:91). Calls GET /api/update.
  3. 204: nothing new
    System: No body; the app does nothing.
  4. 200: updater JSON
    System: Tauri updater format with signature and a download URL.
  5. Download through the relay
    System: The relay answers 302 to a short-lived signed asset URL (relay/api/download/[id].ts:21). Calls GET /api/download/{asset-id}.
  6. Verify the minisign signature
    System: Public key in app/src-tauri/tauri.conf.json; a bad signature is never installed.
  7. Install when quiet
    System: quiet_now: no sync running, window hidden, QUIET_AFTER (10 min) since the window was last shown (hidden or destroyed); a never-shown window is quiet at once (updates.rs:41).
  8. Or click "Restart to update"
    System: The Groups screen shows the button when an update is waiting (Groups board).
