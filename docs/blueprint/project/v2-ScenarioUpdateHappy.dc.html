App update from GitHub Releases: happy path

Created 2026-11-26. Updated 2026-11-26.

As a user, I want to get the new version of the app, so that I run the fixed version without reinstalling. Click a step to open its screen. The flow behind it.

Acceptance criteria: Only a valid signature installs. Install waits for an idle moment.
  1. Start, then every 6 h
    System: tauri-plugin-updater with the endpoint below; Check now does the same.
  2. Read latest.json
    System: Public asset; no relay, no token. Calls GET https://github.com/MehdiMamas/claude-sync/releases/latest/download/latest.json.
  3. Newer: download in the background
    System: Downloads to a temp file.
  4. Verify the minisign signature
    System: Public key built into the app.
  5. Install when idle or on Restart
    System: Idle: no sync running and the window closed for 10 minutes.
  6. State: Up to date
    System: UML state machine: App update.
  7. State: Downloaded, verified
    System: UML state machine: App update.
  8. State: Failed, thrown away
    System: UML state machine: App update.
  9. Also: Settings: updated
    System: state "just updated".
