Scheduled jobs (accept, run)

A group can ship scheduled Claude Code jobs in schedules.json. Each job is validated, shown for consent, and registered with the OS scheduler only after the user accepts. Usual failures: an invalid job (listed, never run) and a job that exceeds its timeout (killed with its process tree). Created 2026-11-26. Updated 2026-11-26.
