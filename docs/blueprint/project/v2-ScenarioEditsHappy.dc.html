Local edits, share, propose, revert: happy path

Created 2026-11-26. Updated 2026-11-26.

As a host or member, I want to share (host) or propose (member) a change I made locally, so that the group can use it after another member approves and the host merges. Click a step to open its screen. The flow behind it.

Acceptance criteria: Every share is scanned first. Never a force push. A lost race keeps the local copy. The author never approves their own proposal.
  1. Watcher sees a changed shared file
    System: fs::watch (notify crate), 500 ms debounce; the hash differs from the base.
  2. Local edits list
    System: Share, Undo, Keep mine, Copy to group.
  3. Share: preview the diff
    System: engine::secrets::scan runs on every line before the preview shows.
  4. Host: upload changed blobs and a tree
    System: One blob per changed file (1 MiB limit per plugin file), then a tree on the base. Calls POST /repos/{owner}/{repo}/git/blobs.
  5. Make the tree
    System: base_tree plus the changed paths. Calls POST /repos/{owner}/{repo}/git/trees.
  6. Commit
    System: The commit names the author login. Calls POST /repos/{owner}/{repo}/git/commits.
  7. Fast-forward main
    System: force is never used; 422 means someone pushed first. Calls PATCH /repos/{owner}/{repo}/git/refs/heads/main.
  8. Member (or anyone in proposal mode): write the proposal
    System: Blobs, tree and commit as above, on a new branch.
  9. Make the proposal branch
    System: proposal/<login>-<yyyymmddHHMMSS>. Calls POST /repos/{owner}/{repo}/git/refs.
  10. Open the proposal pull request
    System: Base main; shows on every member's Proposals card on their next tick. Calls POST /repos/{owner}/{repo}/pulls.
  11. Another member approves
    System: The author cannot approve their own. Calls POST /repos/{owner}/{repo}/pulls/{n}/reviews.
  12. Read the approvals
    System: Only for proposals that changed since the last tick. Calls GET /repos/{owner}/{repo}/pulls/{n}/reviews.
  13. Host merges (or Accept all approved)
    System: Merge the pull request; members get it next tick. Calls PUT /repos/{owner}/{repo}/pulls/{n}/merge.
  14. History tab
    System: The commit list of main. Calls GET /repos/{owner}/{repo}/commits.
  15. Revert a commit, after a preview
    System: The preview is the compare of the commit with its parent; the revert is a new commit. Calls GET /repos/{owner}/{repo}/compare/{base}...{head}.
  16. State: Open
    System: UML state machine: Proposal.
  17. State: Approved, merged
    System: UML state machine: Proposal.
  18. State: Declined, closed
    System: UML state machine: Proposal.
  19. Also: Group: copy to another group
    System: state "copy preview".
  20. Also: Group: contents
    System: state "contents listed".
  21. Also: Group: no history yet
    System: state "empty: no history".
  22. Also: Group: proposal mode on
    System: state "proposal mode on".
  23. Also: Group: approval sent
    System: state "member approval sent".
  24. Also: Group: local edit undone
    System: state "edit undone".
  25. Also: Group: local edit kept
    System: state "edit kept local".
