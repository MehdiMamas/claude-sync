claude-sync is a small desktop app (Windows, macOS, beta Linux) that shares a Claude Code setup with a group through a private GitHub repo. This page is v1 as-is plus two reviewed changes (see Decisions). The screens are the product as it runs at commit 5ea0f8d: 22 screen states rebuilt from the live app, ten flows with edge cases, the architecture and the design.
