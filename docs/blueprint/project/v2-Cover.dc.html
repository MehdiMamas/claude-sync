What v2 is: the whole app (UI and engine) rewritten from scratch. Tauri 2 shell, a new Rust engine (pure planner + one executor, REST with ETags), SQLite store, React + TypeScript window, one CLI, updates straight from GitHub Releases, relay only for feedback. Every v1 ability is kept except five listed on Parity. Why each choice: Decisions.
