Engine 5: CLAUDE.md review, clashes, sharing, local edits

How shared CLAUDE.md lines reach a device, how clashes are found and how own text is shared. Created 2026-11-26. Updated 2026-11-26.

#Step or thingExact behaviour, values and errorsEvidence
1Three textsPer group, in groups/<g>/claude-md-review.json (format 2): group (the group CLAUDE.md as last seen), accepted (what the copy should hold: group text plus this user's decisions) and the copy itself, which the user may edit (an unshared local edit).crates/core/src/review.rs:1-20
2ItemsA change is split into items: one block of added lines or one block of removed lines (Kind add|remove), each with id, lines, up to CONTEXT = 2 lines before and after, pos, author (GitHub login), commit and message. Items by the same login (any device) apply at once; items by others wait as pending. A declined item is never applied or asked again (MAX_DECLINED = 500 remembered). Patching is by content, not line number. Diffs above MAX_DIFF_CELLS = 4,000,000 are reported as removed-then-added.crates/core/src/review.rs:21-60
3Review switchreview = per-device override (choices.reviewClaudeMd) or, if unset, !group autoAcceptClaudeMd. ClaudeMdReview fields: review, auto_accept, review_override, differs, declined (count), pending. When review ends up off, pending items are accepted.crates/core/src/engine.rs ClaudeMdReview
4Decidedecide_claude_md accepts or declines by ids or all. Accepted items are written to the copy; nothing is pushed. use_group_claude_md resets pending and declined, clears dropped_lines and removes shared[CLAUDE.md]. An error: "{id} has no CLAUDE.md on this device to review".crates/core/src/engine.rs:2015
5Share own textThe text is the user's own ~/.claude/CLAUDE.md minus the managed block and import lines, secrets redacted. It is appended under the heading "## {login}", or becomes the first CLAUDE.md of a new group. Nothing is committed when the group already holds the text. The own file is backed up before the shared lines are removed (option remove_own).crates/core/src/engine/claude_md.rs
6Clash detectionDeterministic, at most 200 clashes. Duplicate: equal after ignoring case, list markers, punctuation and spacing, or apart from filler words. Contradiction: equal apart from a negation. Rule lines exclude headings, code blocks, imports, comments, tables and lines with fewer than 2 words. Settings clash when two groups set the same plain value differently; arrays never clash.crates/core/src/conflicts.rs
7Resolve a clash"Keep this one" declines the other group's line for this user only (choices droppedLines; own text is backed up first). Only "Edit" of a group's line commits to that group.crates/core/src/engine/conflicts.rs
8Local edits bannerwatch.rs local_edits compares the disk with the manifest of what was applied. Undo restores the group's version; Share pushes the file through the normal engine push (host, or proposal when proposalMode).crates/core/src/watch.rs
9Conflicts listFiles changed on both sides are merged three-way; unmergeable ones are kept under conflicts_dir/<utc_stamp>/path and listed (at most 50).crates/core/src/engine.rs:200
