Colour tokens

Status: current. Created 2026-11-26. Updated 2026-11-26.

Light values are the :root block of app/ui/src/style.css, dark values its prefers-color-scheme block. Each row says what the colour sits on and what contrast that gives. The app border colour --line (a pale grey, 1.2:1 on --bg) is not a row: at 1.2:1 on --bg it fails the 3:1 rule for UI parts, so these frames draw their dividers as --muted at 35%. v2 decision: control borders use --muted (see Decisions); --line stays only for dividers inside a card. The screen frames below are still drawn as in v1 until the change is built.
