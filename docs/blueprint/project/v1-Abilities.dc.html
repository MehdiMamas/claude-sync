72StartupAutostart launches the app with --background, which starts in the tray only if signed in. Single instance: a second launch opens the existing window, but a launch with --refresh only reloads the screens. 73JobsLimits of group scheduled jobs in schedules.json: at most 20 jobs; prompt up to 4096 bytes; id 1 to 41 bytes, first character a lowercase letter or digit, then lowercase letters, digits or hyphens; timeout default 60 and maximum 240 minutes; permission mode one of default, acceptEdits, plan, bypassPermissions; extra args only --chrome, --model, --effort (effort low, medium, high, xhigh or max). The job is registered with the OS scheduler only after the person accepts it. (crates/core/src/jobs/mod.rs:31-40,161-167; README.md Group scheduled jobs)Group: Jobs card
74JobsA run while the machine is offline records the result "skipped: offline" and does not run. The 20 newest logs per job are kept (KEEP_LOGS = 20; logs/jobs/<id>/<UTC stamp>.log). A run takes a lock on the job; a lock older than timeout*60 + 300 seconds (STALE_GRACE_SECS = 300) is stale: it is removed with the warning "breaking a stale job lock", and is_running ignores it. (crates/core/src/jobs/run.rs:17-19,80,226-227,254)Invisible; job log, Jobs card result
75JobsJob PATH on macOS: launchd gives only /usr/bin:/bin:/usr/sbin:/sbin, so the run sets PATH to the login shell PATH plus the current PATH, claude's directory and the standard bin directories; hooks that call node or gh then work. (jobs/run.rs; commit f7a83af, #88)Invisible; OS scheduler
76PlatformDifferences by system: macOS and Linux release app links ~/.local/bin/claude-sync at startup (only if the folder exists and the name is free); Windows has no shim and its release exe is a GUI program, so output must be piped (Out-String, #149). Jobs run through Task Scheduler (Windows), launchd (macOS) or a systemd user timer (Linux, beta, needs a tray AppIndicator and a Secret Service keyring). Token store: Credential Manager, Keychain, Secret Service. Installers: README says not code-signed or notarized; docs/releasing.md says macOS is signed when the APPLE_* secrets exist. (AGENTS.md Command line; README.md Install; jobs/os.rs)Terminal; OS scheduler
77UpdatesDelivery: the app asks the relay (target, arch, current version, Bearer token, 60 s timeout), downloads in the background and installs at a quiet moment (no sync running, window hidden, window last shown at least 10 minutes ago or never) or on Quit or Restart to update. Bundles are minisign-signed (TAURI_SIGNING_PRIVATE_KEY). RELAY_URL defaults to an .invalid host, so a build without CLAUDE_SYNC_RELAY_URL has updates and feedback off. (config.rs:6-9,56-58; updates.rs:16,41-50,103-138,176-235; README.md Building)Settings, Updates
