Create a group, invite, join: happy path

Created 2026-11-26. Updated 2026-11-26.

As a host, I want to create a group and invite a friend, so that my friends get my shared Claude setup. Click a step to open its screen. See the flow that leads here.

  1. Click "Create group"
    System: The create form opens in place (GroupsCreate board).
  2. Fill name and submit
    System: The form asks for a group name; a name is required.
  3. Create private repo + claude-sync.json
    System: engine.create_group (crates/core/src/engine.rs:639) creates the repo on the host account with the topic claude-sync-group.
  4. Repo ruleset: only admins push
    System: Host lock is on unless GitHub does not allow it (architecture section 5a; engine.rs:1324 refuses non-hosts).
  5. Add member login
    System: engine.add_member (engine.rs:742) sends a GitHub collaborator invitation.
  6. Invitation shows on Groups
    System: invitations_loop polls every 15 minutes (app/src-tauri/src/config.rs:49).
  7. Click Accept
    System: engine.accept_invitation (engine.rs:702) accepts, joins and runs the first sync.
  8. First sync places the group files
    System: Files land in ~/.claude and ~/.claude-sync/groups/<owner>__<repo>/base/.
