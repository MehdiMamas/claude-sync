UML activity diagram: Local edits, share, propose, revert

A file watcher marks shared files the user changed. The user shares (host), proposes (member), undoes or keeps it. Every share is scanned for secrets first. The host can revert a group commit. Red: a secret is found, or both sides changed one file. Created 2026-11-26. Updated 2026-11-26.
