Sign in with GitHub (device code)

The user signs in once per device. The app asks GitHub for a device code, shows it, polls until the user approves it on github.com, then keeps the tokens in the OS keychain. Usual failure: the code expires before the user enters it (red). Created 2026-11-26. Updated 2026-11-26.

Why a device code
The app has no web server to receive a redirect, so GitHub OAuth device flow is used with a public client id and no secret (docs/architecture.md section 3).
