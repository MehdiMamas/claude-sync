Sign in with GitHub (device code): happy path

Created 2026-11-26. Updated 2026-11-26.

As a new user, I want to sign in with my GitHub account, so that I can use the app without a separate password. Click a step to open its screen. The flow behind it.

Acceptance criteria: The code shows within 2 s of the click. The token is only in the keychain. A 401 later stops all loops and says so.
  1. Click Sign in with GitHub
    System: The window sends the command auth.start to the engine actor.
  2. GitHub returns user_code and URL
    System: github::device::start posts the public client id with scopes repo and read:user. Calls POST https://github.com/login/device/code.
  3. Show the code, open github.com/login/device
    System: Copy code puts it on the clipboard; Cancel drops the poll task.
  4. Copy the code, paste it on github.com
    System: In the browser, outside the app.
  5. Poll every interval, slow down when told
    System: github::device::poll honours interval and slow_down (adds 5 s). Calls POST https://github.com/login/oauth/access_token.
  6. Store the token in the keychain, read the login
    System: store::secrets writes one keychain entry; GET /user gives the login. Calls GET /user.
  7. Open Groups
    System: The window asks for the snapshot and renders Groups.
  8. App mode: list installations
    System: Only when the GitHub App sign-in (beta) is on. Calls GET /user/installations.
  9. App mode: repos the user picked
    System: Groups outside the picked repos show as not reachable. Calls GET /user/installations/{id}/repositories.
  10. App mode: refresh the token before expiry
    System: The 8-hour token is replaced with the refresh token; a refused refresh ends the session. Calls POST https://github.com/login/oauth/access_token (refresh_token).
  11. State: Signed out
    System: UML state machine: Session.
  12. State: Waiting for approval
    System: UML state machine: Session.
  13. State: Signed in
    System: UML state machine: Session.
  14. State: Sign-in expired
    System: UML state machine: Session.
  15. Also: Settings: sign out
    System: state "confirm sign out".
