Members: invite, remove, transfer, leave, discover: happy path

Created 2026-11-26. Updated 2026-11-26.

As a host, I want to manage who is in my group, so that only the people I trust get my setup. Click a step to open its screen. The flow behind it.

Acceptance criteria: Removal, transfer and leave ask first. An invitation shows as Invited until GitHub says it was accepted.
  1. Open Members
    System: Members and pending invitations are read on open and once a day.
  2. List collaborators
    System: Permissions decide who is host (admin). Calls GET /repos/{owner}/{repo}/collaborators.
  3. List pending invitations
    System: Invited logins are listed apart from members. Calls GET /repos/{owner}/{repo}/invitations.
  4. Invite by GitHub name
    System: A collaborator invitation with push rights. Calls PUT /repos/{owner}/{repo}/collaborators/{login}.
  5. Cancel an invitation
    System: Deletes the pending invitation. Calls DELETE /repos/{owner}/{repo}/invitations/{id}.
  6. Remove a member, after a confirm
    System: The member's next sync removes the group files from their ~/.claude.
  7. Collaborator removed
    System: Calls DELETE /repos/{owner}/{repo}/collaborators/{login}.
  8. Make another member host, after a confirm
    System: GitHub moves the repo to the new owner; the app follows the new name.
  9. Transfer requested
    System: GitHub emails the new owner; nothing moves until they accept. Calls POST /repos/{owner}/{repo}/transfer.
  10. New owner accepts: repo moved
    System: The app follows the new name; the old host stays a member.
  11. Member: find groups to join
    System: Repos the user can read, then their topics: claude-sync-group marks a group. Calls GET /user/repos?affiliation=owner,collaborator.
  12. Read topics of new repos
    System: Only repos not seen before. Calls GET /repos/{owner}/{repo}/topics.
  13. Member leaves, after a confirm
    System: The group files leave ~/.claude on all their machines.
  14. Own access removed
    System: Calls DELETE /repos/{owner}/{repo}/collaborators/{own login}.
