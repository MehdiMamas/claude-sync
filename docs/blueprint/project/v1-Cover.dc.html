claude-sync: as-is (v1, superseded)

Created 2026-11-26. Updated 2026-11-26.

Status: superseded by v2 (To-be). This page stays as the record of the product as it runs today. Last changed: 2026-11-26.

For: the owner, to review before the To-be version, and anyone rebuilding the app.

claude-sync is a small desktop app (Windows, macOS, beta Linux) that shares a Claude Code setup with a group through a private GitHub repo. This page is the product as it runs at commit 5ea0f8d: 46 screen states and result frames rebuilt from the live app or, where marked, from the code, ten flows with edge cases, the architecture and the design.

To rebuild the app

Seven frame sets hold everything a builder needs without the code: Abilities (every ability and where it shows), Fixed bugs (behaviour not to regress), the rebuild spec (1 data contracts and migration, 2 behaviour rules, 3 non-functional baseline), the Eng engine flows (sign-in, sync pull, group lifecycle, personal and jobs, proposals and revert, review and clashes, settings, marketplaces, watcher), the Msg messages (sign-in and settings, groups, review, commands and jobs, GitHub and helper, engine errors, tray, notifications, CLI), the Feedback frames (app, relay, triage) and the Module spec index with the 64 Module spec frames below.
