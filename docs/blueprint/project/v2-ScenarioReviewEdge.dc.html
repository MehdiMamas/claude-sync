Review CLAUDE.md lines from the group: edge cases

Created 2026-11-26. Updated 2026-11-26.

As a group member, I want to see what happens when it goes wrong while I review what others add to the group CLAUDE.md, so that my Claude never reads lines I did not accept even then. Click a step to open its screen. The flow behind it.

Acceptance criteria: The user sees what went wrong in words, and what to do next. Nothing is lost or half-written.
  1. Lines wait as review items (unless auto-accepted)
    System: The host setting autoAcceptClaudeMd (default on) and each person's choice (Follow group, Review first, Auto-accept) decide; only accepted lines are written into the managed block of ~/.claude/CLAUDE.md.
  2. Clash with own line: choose
    System: Keep mine, use the group line, or edit it.
  3. Read the diff, ask Claude to explain
    System: The helper runs the local claude CLI; no API key, skipped when only own changes.
  4. Claude not signed in: no explain
    System: The helper is optional; review works without it.
