Send feedback through the relay: edge cases

Status: current. Created 2026-11-26. Updated 2026-11-26.

As a user, I want to see what happens when it goes wrong while I send a problem report from the app, so that the maintainer sees it with logs even then. Click a step to open its screen. See the flow that leads here.

  1. POST /api/feedback with the user token
    System: feedback::submit (feedback.rs:172) sends title, description, kind, version, os, logs, screenshot. Calls POST /api/feedback.
  2. Offline or 429/5xx: saved to outbox
    System: save_to_outbox (feedback.rs:288) after a send error (:265); retry_outbox sends later (:297).
  3. 403: account blocked
    System: BLOCKED_GITHUB_USERS returns 403 (relay/lib/auth.ts); the app shows the relay message.
