UML activity diagram: Scheduled jobs from a group

A group can share scheduled Claude jobs. Each job is checked against hard limits and runs only after the user accepts it on this account. The OS scheduler runs the claude-sync CLI, which runs claude with a timeout and keeps the logs. Red: offline at run time. Created 2026-11-26. Updated 2026-11-26.
