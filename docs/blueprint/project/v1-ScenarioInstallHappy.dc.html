Install page for a friend: happy path

Created 2026-11-26. Updated 2026-11-26.

As a friend, I want to download the app from the install page, so that I can install it on my computer. Click a step to open its screen. See the flow that leads here.

  1. Open /install
    System: relay/api/install/page.ts:72. Relay page, not captured. The link target below is the app Sign in screen the friend reaches after installing. Calls GET /install.
  2. Redirect to GitHub sign-in
    System: relay/api/install/login.ts:6 starts the OAuth web flow. Calls GET /api/install/login.
  3. GitHub asks the friend to approve
    System: The friend approves the relay's OAuth app.
  4. Callback sets a signed cookie
    System: relay/api/install/callback.ts:40 exchanges the code and sets an HMAC session cookie. Calls GET /api/install/callback.
  5. Login blocked?
    System: page.ts:83 checks the login against BLOCKED_GITHUB_USERS.
  6. Download installer
    System: The page links to the download route (relay/api/download/[id].ts:21).
  7. Sign out of the install page
    System: Clears the cookie (relay/api/install/logout.ts:5). Calls GET /api/install/logout.
