Sign in with GitHub (device code): edge cases

Created 2026-11-26. Updated 2026-11-26.

As a new user, I want to see what happens when it goes wrong while I sign in with my GitHub account, so that I can use the app without a separate password even then. Click a step to open its screen. See the flow that leads here.

  1. Poll until GitHub says approved
    System: auth::poll waits between polls (auth.rs:157) and handles slow_down and expiry. Calls POST https://github.com/login/oauth/access_token.
  2. Code expired: "Start again"
    System: Poll returns Expired and the error text is "The code expired. Start again." (auth.rs:173, 181).
  3. Save tokens in the OS keychain
    System: One JSON keychain entry; one shared github::Session per sign-in (auth.rs:42).
  4. Later: token refused, sign-in expired
    System: A 401 that refresh cannot cure removes the tokens, the tray says "claude-sync: Sign-in expired", a notification titled "GitHub sign-in expired" appears, and the window shows Sign in again (auth.rs:69-88).
  5. Frame: Sign in: did not finish
    System: sign-in did not finish (built from the app code, not captured).
  6. Frame: Sign in: not available
    System: no client id in this build (built from the app code, not captured).
  7. Frame: Sign in: new code
    System: new code after expiry.
