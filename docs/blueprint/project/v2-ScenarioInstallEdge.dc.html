Install and first start: edge cases

Created 2026-11-26. Updated 2026-11-26.

As a friend, I want to see what happens when it goes wrong while I download and start the app, so that I can join my friends group even then. Click a step to open its screen. The flow behind it.

Acceptance criteria: The user sees what went wrong in words, and what to do next. Nothing is lost or half-written.
  1. Open the Releases page, download
    System: Installers per platform, each signed where the platform allows. Calls GET https://github.com/MehdiMamas/claude-sync/releases/latest.
  2. Unsigned: SmartScreen or Gatekeeper warns
    System: Windows: More info, Run anyway. macOS: right-click, Open. Each release lists SHA-256 sums.
  3. Import v1 state once, if found
    System: store::import_v1 reads the old JSON files into SQLite and keeps them as a backup.
  4. A v1 daemon holds daemon.lock: stopped, or wait shown
    System: v2 sends it SIGTERM and waits up to 30 s for daemon.lock; on timeout nothing is imported.
  5. A v1 file cannot be read: skipped, kept
    System: store::import_v1 reports it; the old folder is kept under ~/.claude-sync/backup/.
  6. Open Sign in
    System: Start at login is turned on at first start.
  7. No client id: sign-in not available
    System: A build without CLAUDE_SYNC_GITHUB_CLIENT_ID says so and stops there.
