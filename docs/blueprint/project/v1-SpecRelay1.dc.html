On a non-OK answer with a cached release and status 403 or 429, the stale release is served with warn `GitHub answered <status> for the latest release; serving the cached one` (signature: `... for signature asset <id>; serving the cached one`). Any other failure, or a 403/429 with nothing cached, throws 502 `GitHub latest release returned <n>` / `GitHub signature asset returned <n>`.errorupdate.ts
Order: requireCaller first (401/403/429), then params: target in windows|darwin|linux else 400 "target must be one of: windows, darwin, linux"; arch in x86_64|aarch64 else 400 "arch must be one of: x86_64, aarch64"; current_version must parse as semver else 400 "current_version must be a semver version".validationupdate.ts
204 (cache-control no-store, empty body) when: no release or it is a draft; tag is not semver (warn `latest release tag <tag> is not semver`); latest <= current (prerelease of the same version is older); bundle or its .sig missing (warn `release <tag> has no <target>/<arch> update bundle with a .sig`).orderupdate.ts
