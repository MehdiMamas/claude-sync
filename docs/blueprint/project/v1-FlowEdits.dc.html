Local edits, conflicts, proposals

The app watches the managed files. When the user edits one, the Group screen asks what to do. A host pushes a commit. A member in proposal mode opens a pull request from a proposal/<login> branch. Usual failure: a conflict, where the remote wins and the local copy is kept aside. Created 2026-11-26. Updated 2026-11-26.
