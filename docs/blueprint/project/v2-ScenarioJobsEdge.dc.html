Status: current. Created 2026-11-26. Updated 2026-11-26.

As a group member, I want to see what happens when it goes wrong while I accept a scheduled job before it runs, so that nothing runs on my computer without my yes even then. Click a step to open its screen. See the flow that leads here.

  1. Validate every job
    System: parse_file (crates/core/src/jobs/mod.rs:264): id regex (:161), 5-field cron, args allowlist (:122), 1-240 min timeout, at most 20 jobs.
  2. Invalid job: listed as a problem
    System: Problem entries show why; the job never runs (mod.rs:95).
  3. Show job, ask Accept
    System: Consent is a SHA-256 over cron, prompt, cwd, permissionMode, timeout and args (consent_hash, mod.rs:67).
  4. Job text changed: consent hash differs
    System: A new hash means the user must accept again before it runs.
