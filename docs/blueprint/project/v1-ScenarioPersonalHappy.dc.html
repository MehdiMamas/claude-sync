Personal memory sync: happy path

Created 2026-11-26. Updated 2026-11-26.

As a person with two computers, I want to keep my own CLAUDE.md and memory in step, so that both computers act the same. Click a step to open its screen. See the flow that leads here.

  1. Open Settings > Personal memory
    System: Personal memory is off or offered (SettingsOff, SettingsOffer boards).
  2. Click Turn on
    System: Window calls personal_enable (crates/core/src/personal.rs:314).
  3. Create private repo <login>/claude-sync-personal
    System: The private repo is created once (engine.rs:3468 create_personal_repo).
  4. Choose what to sync (3 switches)
    System: CLAUDE.md, memory and mod settings (personal_set_kinds, personal.rs:351).
  5. Merge + push local files
    System: personal_sync (personal.rs:466) merges and pushes; secrets are scanned first (secrets::scan, engine.rs:410).
  6. Other device: "Join this memory?"
    System: personal_check_new_device (personal.rs:419) offers a join; Dismiss calls personal_dismiss_offer (personal.rs:457).
  7. Accept: files pulled and merged
    System: New devices can also join automatically (personal_set_new_devices_join, personal.rs:377).
  8. Frame: Settings (2/4)
    System: default.
  9. Frame: Settings (3/4)
    System: default.
  10. Frame: Settings (4/4)
    System: default.
