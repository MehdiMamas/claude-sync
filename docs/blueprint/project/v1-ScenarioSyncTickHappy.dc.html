Background sync tick: happy path

Created 2026-11-26. Updated 2026-11-26.

As a group member, I want to have changes arrive on their own, so that my setup stays current without me clicking. Click a step to open its screen. See the flow that leads here.

  1. Timer wakes (60 s or reset + 5 s)
    System: background.rs:29 loops; next_wake (background.rs:57) uses DEFAULT_POLL_SECONDS 60 (config.rs:47).
  2. One GraphQL call: all heads + names
    System: heads_query builds aliases r0..rN (github/graphql.rs:21); one call per tick. Calls POST https://api.github.com/graphql.
  3. GitHub returns heads
    System: parse_heads (graphql.rs:37) maps each repo to its head.
  4. Head changed? (ETag 304 cache)
    System: Unchanged groups cost no download. One in-memory GET cache keyed by URL (AGENTS.md gotchas).
  5. Download only changed blobs
    System: Files are reused from the base by git blob sha (remote.rs:24; files_matching remote.rs:616).
  6. Three-way merge with the base
    System: Remote wins on conflict; the local copy is saved to conflicts/<group>/<UTC> (paths.rs:75).
  7. Write files, update base + manifest
    System: The apply layer writes ~/.claude files and records the new head.
  8. Update tray and Groups status
    System: after_sync refreshes status; last_sync_unix shows on the card.
  9. State: Syncing (on)
    System: state on in Group states on a device (GroupStatus in crates/core/src/engine.rs:36; groupOff and rate_limited_until).
  10. State: Turned off on this device
    System: state off in Group states on a device (GroupStatus in crates/core/src/engine.rs:36; groupOff and rate_limited_until).
  11. State: Waiting for rate limit
    System: state limited in Group states on a device (GroupStatus in crates/core/src/engine.rs:36; groupOff and rate_limited_until).
  12. State: Last sync failed
    System: state error in Group states on a device (GroupStatus in crates/core/src/engine.rs:36; groupOff and rate_limited_until).
  13. Frame: Notifications
    System: default.
  14. Frame: Notifications: empty
    System: no notifications.
  15. Frame: Notifications: cleared
    System: cleared toast.
