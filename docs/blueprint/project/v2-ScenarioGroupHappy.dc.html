Create a group and invite a member: happy path

Created 2026-11-26. Updated 2026-11-26.

As a host, I want to create a group and invite a friend, so that my friends get my shared Claude setup. Click a step to open its screen. The flow behind it.

Acceptance criteria: The repo is private. Only the host can push to main. A refused join writes nothing.
  1. New group, type a name
    System: The form checks the name locally against GitHub repo name rules.
  2. Make the private repo
    System: github::repos::create with private=true and auto_init. Calls POST /user/repos.
  3. Lock main to admins
    System: A ruleset so only the host pushes; members propose by pull request. Calls POST /repos/{owner}/{repo}/rulesets.
  4. Invite a member by name
    System: The engine sends a collaborator invitation. Calls PUT /repos/{owner}/{repo}/collaborators/{login}.
  5. Invitation shows on Groups
    System: The invitations loop runs every 15 minutes and on window open. Calls GET /user/repository_invitations.
  6. Accept
    System: Accept, then read the repo (name, private, permissions). Calls PATCH /user/repository_invitations/{id}.
  7. First sync places the files
    System: The same planner as every tick; the group joins the order list last. Calls GET /repos/{owner}/{repo}.
  8. Also: Groups
    System: state "default".
  9. Also: Groups: none yet
    System: state "empty: no groups".
  10. Also: Groups: order changed
    System: state "order changed".
  11. Also: Group: overview (host)
    System: state "host view".
  12. Also: Group: turned off
    System: state "turned off for you".
  13. Also: Group: members (host)
    System: state "members, host".
  14. Also: Group: members (member)
    System: state "members, read only".
  15. Also: Group: transfer host
    System: state "confirm transfer".
  16. Also: Group: leave
    System: state "confirm leave".
  17. Also: Group: invite canceled
    System: state "invitation canceled".
  18. Also: Group: remove member
    System: state "confirm remove".
  19. Also: Group: member removed
    System: state "member removed".
  20. Also: Group: host transferred
