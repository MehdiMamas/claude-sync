Core library device-flow loop (wait_for_token, used by core tests only; the running app polls with its own loop in SpecTauri2 auth.rs:157-201: minimum interval 5 s, deadline max(expires_in, 60) s, sleep before the expiry check): interval = max(code.interval, 1) s; waited = 0.
