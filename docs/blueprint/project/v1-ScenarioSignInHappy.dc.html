Sign in with GitHub (device code): happy path

Created 2026-11-26. Updated 2026-11-26.

As a new user, I want to sign in with my GitHub account, so that I can use the app without a separate password. Click a step to open its screen. See the flow that leads here.

  1. Click "Sign in with GitHub"
    System: The Sign in screen has one primary button. Nothing is stored yet.
  2. Ask the backend for a code
    System: The window calls the Tauri command that runs auth::start (app/src-tauri/src/auth.rs:94).
  3. GitHub returns user_code + URL
    System: The app POSTs the public client id and scopes repo and read:user. Calls POST https://github.com/login/device/code.
  4. Show the code, open github.com/login/device
    System: The code screen shows the code and a Cancel button (SignInCode board).
  5. Enter the code on github.com
    System: Done in the browser, outside the app. The app cannot see it.
  6. Poll until GitHub says approved
    System: auth::poll waits between polls (auth.rs:157) and handles slow_down and expiry. Calls POST https://github.com/login/oauth/access_token.
  7. Save tokens in the OS keychain
    System: One JSON keychain entry; one shared github::Session per sign-in (auth.rs:42).
  8. Open the Groups screen
    System: The window reloads its state and lands on Groups.
  9. State: Signed out
    System: state out in Sign-in states (app/src-tauri/src/auth.rs:35-250; app/ui/src/screens/signInScreen.ts).
  10. State: Waiting for code approval
    System: state code in Sign-in states (app/src-tauri/src/auth.rs:35-250; app/ui/src/screens/signInScreen.ts).
  11. State: Signed in
    System: state in in Sign-in states (app/src-tauri/src/auth.rs:35-250; app/ui/src/screens/signInScreen.ts).
  12. State: Sign-in expired
    System: state expired in Sign-in states (app/src-tauri/src/auth.rs:35-250; app/ui/src/screens/signInScreen.ts).
  13. Frame: Sign in: asking GitHub
    System: asking GitHub for a code (built from the app code, not captured).
  14. Frame: Sign in: code copied
    System: code copied toast.
  15. Frame: Sign in: GitHub opened
    System: GitHub opened in browser.
  16. Frame: Signed in: loading groups
    System: approved, groups loading (built from the app code, not captured).
