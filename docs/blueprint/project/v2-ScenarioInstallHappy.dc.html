Install and first start: happy path

Created 2026-11-26. Updated 2026-11-26.

As a friend, I want to download and start the app, so that I can join my friends group. Click a step to open its screen. The flow behind it.

Acceptance criteria: A v1 install is imported once, its files kept. Closing the window never quits.
  1. Open the Releases page, download
    System: Installers per platform, each signed where the platform allows. Calls GET https://github.com/MehdiMamas/claude-sync/releases/latest.
  2. Start the app: tray icon, one instance
    System: A second start opens the existing window.
  3. Import v1 state once, if found
    System: store::import_v1 reads the old JSON files into SQLite and keeps them as a backup.
  4. Open Sign in
    System: Start at login is turned on at first start.
  5. Put the claude-sync CLI on PATH
    System: Windows: the installer adds the console claude-sync.exe to the user PATH. macOS and Linux: a ~/.local/bin/claude-sync link when the folder exists and the name is free.
  6. Use the tray menu
    System: Sync now, Open, Notifications, Pause, Turn groups off (all groups), Send feedback, Quit.
  7. Quit
    System: The app stops; closing the window never quits.
