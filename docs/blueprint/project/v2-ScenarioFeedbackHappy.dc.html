Send feedback through the relay: happy path

Status: current. Created 2026-11-26. Updated 2026-11-26.

As a user, I want to send a problem report from the app, so that the maintainer sees it with logs. Click a step to open its screen. See the flow that leads here.

  1. Open Send feedback
    System: The nav item opens the form (Feedback board).
  2. Type, attach logs or screenshot
    System: Logs (feedback.rs:64), capture screen (:71), attach file (:104), paste (:114); images are resized under 3 MB (:134).
  3. Click Send
    System: An empty form is refused in the window (FeedbackEmpty board).
  4. POST /api/feedback with the user token
    System: feedback::submit (feedback.rs:172) sends title, description, kind, version, os, logs, screenshot. Calls POST /api/feedback.
  5. Relay creates the issue as the user
    System: Attachments go to a private attachments repo; labels and sprint milestone use the relay token (docs/architecture.md section 12).
  6. Returns {number, url}
    System: The relay answers with the new issue number and URL.
  7. Show the link to the issue
    System: The window links to the issue it created.
