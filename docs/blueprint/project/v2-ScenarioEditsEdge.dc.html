Local edits, conflicts, proposals: edge cases

Status: current. Created 2026-11-26. Updated 2026-11-26.

As a group member, I want to see what happens when it goes wrong while I share or propose a change I made locally, so that the group can use it after the host agrees even then. Click a step to open its screen. See the flow that leads here.

  1. Group lists "Local changes" with actions
    System: Each edit offers a choice; engine.resolve_edit applies it (engine.rs:971).
  2. Conflict: remote wins, local copy kept
    System: Conflicts list on the Group screen; the copy lives in conflicts/<group>/<UTC> (paths.rs:75).
  3. Secret scan before any commit
    System: Blocked when a pattern matches (secrets::scan, engine.rs:410), unless the line has claude-sync: allow-secret.
  4. Secret found: change refused
    System: The edit is not pushed and the pattern name is shown (helper.rs:171 uses first_hit).
