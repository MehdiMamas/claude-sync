Background sync tick: edge cases

Status: current. Created 2026-11-26. Updated 2026-11-26.

As a group member, I want to see what happens when it goes wrong while I have changes arrive on their own, so that my setup stays current without me clicking even then. Click a step to open its screen. See the flow that leads here.

  1. One GraphQL call: all heads + names
    System: heads_query builds aliases r0..rN (github/graphql.rs:21); one call per tick. Calls POST https://api.github.com/graphql.
  2. GraphQL failed: REST fallback
    System: If the GraphQL call fails the engine asks each repo with head_if_changed (remote.rs:601) instead.
  3. Head changed? (ETag 304 cache)
    System: Unchanged groups cost no download. One in-memory GET cache keyed by URL (AGENTS.md gotchas).
  4. Rate limited: no request until reset
    System: run_sync stops before any request when limited (background.rs:96); the card shows the time (rate_limited_until, engine.rs:46).
