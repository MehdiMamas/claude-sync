1MergeObjects merge key by key. Arrays: shared items missing locally are added after the local ones, without duplicates. Plain values: the shared value wins. A local object or array where the group has another type is skipped and the key is reported.crates/core/src/settings.rs
2OwnershipThe app records owned pointers (pointer to value) and array items it added. A value the group no longer ships is removed only if it still equals what the app set; emptied objects are pruned. A value the user changed is not reverted while the group's value is unchanged; it is reported by edited_pointers and carried into sharing by reconstruct.crates/core/src/settings.rs
3Never appliedapiKeyHelper; env values the secret scan flags; hooks with absolute paths.crates/core/src/settings.rs
4Canary ruleA canary is enabledPlugins["<name>@claude-mods"] = false AND env.CLAUDE_CODE_PLUGIN_DIRS holding a path ending in mods/<name> (split on ":" or ";"). After a merge the local value is put back, and canary entries are not counted as edits.crates/core/src/settings.rs
5Personal copy of settingsStrips apiKeyHelper, permissions.additionalDirectories, canary overrides and absolute-path strings before it is uploaded to the personal repo.crates/core/src/personal/settings_file.rs
6File formatWritten with 2-space indent, LF, trailing newline. A UTF-8 BOM is accepted on read. A file that is not one JSON object: "{path} is not one JSON object; nothing was merged".crates/core/src/settings.rs; error.rs:26
7Marketplace placementplugins/<name>/ of a group is placed at <state_dir>/marketplaces/<name>/ and registered in settings.json as extraKnownMarketplaces.<name> (a directory source). That value belongs to the app and wins over a shared value; settings.json is backed up first. Placed only if .claude-plugin/marketplace.json has name == folder name and no earlier group placed it (else a collision on plugins/<name>).crates/core/src/apply/marketplaces.rs
8COMMIT fileEach placed marketplace root gets COMMIT: the group main sha, then the committer date. Written only when changed, removed with the marketplace, never a local edit, not part of a mod fingerprint.crates/core/src/apply/marketplaces.rs; AGENTS.md
9Walk exclusionsSkipped: links, atomic-write temp files, allowlist-refused paths, Claude-generated files (.claude-plugin/types/**, mods/<name>/tsconfig.json) and paths matched by a .gitignore inside the tree. Files over MAX_PLUGIN_FILE 1 MiB are not synced ("{path}: larger than 1 MiB, so it is not synced"). Files the user adds inside a placed folder show as local edits.crates/core/src/apply/marketplaces.rs; group.rs
10UpdateWhen a group's plugins change, the next sync rewrites the folder and COMMIT; a notification says the plugins changed (PLUGINS_CHANGED) and the group page shows "Plugins of this group are missing" until Claude Code has them.app/src-tauri/src/background.rs:296; screens/group.ts
