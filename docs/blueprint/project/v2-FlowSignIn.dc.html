UML activity diagram: Sign in with GitHub (device code)

One sign-in per machine. The engine asks GitHub for a device code, the window shows it, the engine polls until it is approved, then stores the token in the system keychain. Red: the code expires, or GitHub later refuses the token. Created 2026-11-26. Updated 2026-11-26.
