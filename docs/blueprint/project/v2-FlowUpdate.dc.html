UML activity diagram: App update from GitHub Releases

The app reads a static latest.json from GitHub Releases at start and every 6 hours, downloads a newer bundle, checks its minisign signature, and installs at a quiet moment or on Restart to update. Red: the signature fails. Created 2026-11-26. Updated 2026-11-26.
