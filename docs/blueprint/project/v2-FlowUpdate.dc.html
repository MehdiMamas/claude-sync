App update through the relay

At start and every 6 hours the app asks the relay whether a newer release exists, downloads the signed bundle through the relay, checks the minisign signature and installs it when nothing is happening. Usual failure: the relay or GitHub is rate limited, so the app tries later. Status: current. Created 2026-11-26. Updated 2026-11-26.
