Request counters: per (caller, endpoint, result) totals since start plus per-minute buckets; window WINDOW_MINUTES = 10. The app writes them to requests.json in the state dir (once a minute); `claude-sync status` reads them. Snapshot JSON = {since (unix start of counting), last10min: [Entry], total: [Entry]}; Entry = {caller, endpoint, result, count}.namerequests.rs:1-60
Caller tag is a task-local: with_caller(name, future) tags every request in that task; no tag -> caller "other".namerequests.rs:11-24
Counts live in memory only and start at process start: since = the time this GitHub client set was created. A restart begins again at zero and the next write replaces requests.json. Totals are never pruned; only per-minute buckets are. Entries sort by count descending, ties by caller, endpoint, then result text.orderrequests.rs:49-67
record: result label is "304" for 304, "200" for any 2xx, otherwise "other" (so 404, 403, 5xx all "other"); endpoint label = "<METHOD> <normalized path>".
