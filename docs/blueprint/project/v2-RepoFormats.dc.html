Repo formats (shared with v1)

Created 2026-11-26. Updated 2026-11-26.

v2 reads and writes exactly the v1 formats, so v1 and v2 machines share the same group and personal repos during the switch. The v1 module spec frames are normative for every byte: SpecIndex, SpecApply1, SpecPersonal1, SpecEngine1, SpecGithub1, SpecJobs1. Unknown keys are kept on write.

Coexistence rule

  • A v2 client never rewrites a file it did not change, and keeps keys it does not know.
  • A new key or file needs a version bump in claude-sync.json, and v1 must ignore it safely; until every member runs v2, v2 writes nothing new.
  • Plan step 1 runs fixtures copied from real v1 repos (sample data only) through read and write and compares bytes.
