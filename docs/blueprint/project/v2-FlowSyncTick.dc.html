Background sync tick

Every minute (default 60 s) the app asks GitHub for the heads of all groups in one GraphQL call, downloads only changed blobs, merges three ways and writes files. Usual failure: GitHub rate limit, then the loop sleeps until the reset plus 5 seconds. Status: current. Created 2026-11-26. Updated 2026-11-26.

Why REST and GraphQL, no git
No git binary is needed on a friend's PC. REST and GraphQL calls are cheap with ETags and blob-sha reuse (docs/architecture.md section 6).
