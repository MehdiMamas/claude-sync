Usage `<file> [<file>.sig] [--pubkey <base64>]` (pubkey default plugins.updater.pubkey in app/src-tauri/tauri.conf.json). Public key = minisign block: bytes "Ed" + 8-byte key id + 32-byte Ed25519 key (42 bytes). Signature file is base64 of a minisign text block; 74-byte signature (alg 2 + key id 8 + sig 64). Key ids shown as little-endian upper-case hex; mismatch -> "signed with key <A>, but tauri.conf.json has key <B>". "ED" = signature over BLAKE2b-512 of the file (what Tauri writes), "Ed" over the file; else "unknown signature algorithm". Trusted comment must start "trusted comment: " and its global signature (over sig+comment) must verify.
