CLAUDE.md review

When someone else changes the group CLAUDE.md, the change is split into items per commit. Auto-accept is the default; when a group turns review on, each item waits for Accept or Decline. Declined lines are never pushed back. Usual failure: the same lines change again while an item waits. Status: current. Created 2026-11-26. Updated 2026-11-26.
