Visual direction

Status: current. Created 2026-11-26. Updated 2026-11-26.

Palette and type from: app/ui/src/style.css

claude-sync is a small settings utility for a few friends who share a Claude Code setup. The window is read at a glance, a few times a week.

Three adjectives

  • Plain: system-ui at 14px, no brand font, no decoration beyond the tray logo.
  • Calm: a pale grey page, white cards and one blue accent; red only for failures, amber only for waiting.
  • Honest: every state is a word (Synced 7 min ago, Rate limited until...), never a colour alone.

One detail only this subject has

The circular arrows logo in the sign-in screen and tray: it is the sync metaphor and the only graphic in the product.

Dark theme

The app follows the system theme (style.css line 25). These frames show the light theme; dark values are in the token table. Diagram frames are always drawn on the dark panel values so flows look the same in both themes.
