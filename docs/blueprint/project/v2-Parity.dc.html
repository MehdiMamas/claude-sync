Created 2026-11-26. Updated 2026-11-26.

Every row of the v1 Abilities frame (1 to 77), plus abilities the v1 canvas missed or merged (78 to 86). 77 kept, 9 changed, 1 dropped. "Done" for v2 needs this table checked row by row against the old code, and a tester doing the old app's daily tasks.

Dropped, each with its reason

  • 30. Dropped: the v0 layout migration. v2 imports v1 state once (store::import_v1). Reason: v1 already moved every v0 install on start; an install still on v0 runs v1 once first.
