Install page for a friend

A friend opens the relay install page, signs in with GitHub and gets the download buttons. Any GitHub login may download unless it is in the blocked list of the relay. The page is relay HTML, not an app screen, so no board of it exists here. Usual failure: the relay has no install sign-in configured, or the login is blocked. Status: current. Created 2026-11-26.
