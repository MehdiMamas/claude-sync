Budgets (measured in CI)

Created 2026-11-26. Updated 2026-11-26.

Installer size, UI JavaScript and idle GitHub requests fail CI when crossed: they are deterministic. Time, CPU, memory and disk are recorded by the bench job (windows-latest, macos-latest, ubuntu-22.04) and reported, not gated, because hosted runners vary. v1 was never measured, so these are targets; the first v2 bench run records the baseline.
