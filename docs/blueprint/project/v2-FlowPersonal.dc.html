Personal memory sync

One person's CLAUDE.md, memory and mod settings follow them to their other devices through a private repo of their own. The user turns it on in Settings; a second device is offered to join. Usual failure: the same lines with different line endings must not cause a push. Status: current. Created 2026-11-26. Updated 2026-11-26.
