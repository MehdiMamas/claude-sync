Engine 1: sign-in, tokens, GitHub App

Device-flow sign-in end to end: inputs, polling, outputs, token layouts and expiry. Created 2026-11-26. Updated 2026-11-26.

#Step or thingExact behaviour, values and errorsEvidence
1StartPOST /login/device/code with client_id and scope SCOPES. Reply: user_code, verification_uri, expires_in (900 s), interval (5 s). The browser is opened on verification_uri. A build without CLAUDE_SYNC_GITHUB_CLIENT_ID answers "This copy of claude-sync was built without a GitHub client ID (CLAUDE_SYNC_GITHUB_CLIENT_ID), so it cannot sign in."app/src-tauri/src/auth.rs; crates/core/src/github.rs
2PollApp layer (auth.rs:157-201): every max(interval, 5) s until the deadline max(expires_in, 60) s; the core library loop wait_for_token (github.rs:141-163, minimum 1 s, expiry counted in slept seconds) is only used by tests. authorization_pending: keep going. slow_down: interval = max(server interval, current + 5). expired_token: "The code expired. Start again." access_denied: "Sign-in was cancelled on GitHub." A newer sign-in generation cancels the old poll ("cancelled").crates/core/src/github.rs; app/src-tauri/src/auth.rs
3SuccessGET /user, save the token to the OS keychain, set auth, set state.login, emit "signed-in", desktop notification "Signed in" / "claude-sync is signed in as {login}.", then sync soon, check invitations and open the groups window.app/src-tauri/src/auth.rs
4ExpiryDelete the keychain token, emit "sign-in-expired", notify "GitHub sign-in expired" / "Open claude-sync and sign in again to keep syncing. Your groups on this computer are kept." Groups and their files stay on disk.app/src-tauri/src/auth.rs
5Token layoutsKeychain holds either a bare token (0.1.1 and earlier; never starts with "{") or JSON {access_token, refresh_token, expires_at, refresh_token_expires_at} with Unix seconds. User tokens last 8 h, refresh tokens 6 months. REFRESH_MARGIN_SECS = 300: refresh when less than 5 min is left.crates/core/src/github/session.rs
6RefreshSingle flight (one refresh at a time), grant_type=refresh_token, no client secret. A 400 refusal expires the session. A passing network failure keeps the token. A 401 on a call triggers one refresh. A legacy token without a refresh token expires on a confirmed 401.crates/core/src/github/session.rs
7Dev tokenA debug build honours CLAUDE_SYNC_DEV_TOKEN; it stays in memory and never reaches the keychain.app/src-tauri/src/auth.rs
8GitHub App sign-inIssue #39. The same device flow with the App client id (CLAUDE_SYNC_GITHUB_APP_CLIENT_ID, slug CLAUDE_SYNC_GITHUB_APP_SLUG). It reports which wanted repos the App cannot reach and whether it is installed nowhere; install_url and manage_url open GitHub pages for it.crates/core/src/github/app.rs; app/src-tauri/src/config.rs:19-25
9Build-time configCLAUDE_SYNC_GITHUB_CLIENT_ID, CLAUDE_SYNC_GITHUB_APP_CLIENT_ID, CLAUDE_SYNC_GITHUB_APP_SLUG, CLAUDE_SYNC_RELAY_URL are read with option_env! at build time; an empty value disables the feature.app/src-tauri/src/config.rs:6-30
