revert.rs · order, error, name, Revert
Revert = new commit on default branch restoring each allowlisted file touched by the commit to its parent state: added->Delete, deleted->Recreate, else Restore (camelCase serde). Host only (HostOnly). Paths sorted+deduped; files already equal to the target state skipped. revert_preview writes nothing.orderrevert.rs:plan
A file whose head content differs from the commit's result is blocked: '{path} changed again after this commit, in {sha7} by {author}; revert that first.' (no author: '{path} changed again after this commit; revert that first.'). Any blocked file refuses all: 'Nothing was reverted. {messages joined by a space}'.errorrevert.rs:blocked
Empty change set: 'Nothing to revert: the files of {sha7} already match what they were before it'. No parent: '{sha7} is the first commit and cannot be reverted'. Re-check in commit closure: 'Nothing was reverted: {path} changed again while reverting. Try again.' (push race retried).errorrevert.rs:errors
