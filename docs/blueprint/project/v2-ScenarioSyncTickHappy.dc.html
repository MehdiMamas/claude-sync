Background sync tick: happy path

Created 2026-11-26. Updated 2026-11-26.

As a group member, I want to have changes arrive on their own, so that my setup stays current without me clicking. Click a step to open its screen. The flow behind it.

Acceptance criteria: An unchanged repo costs one 304. A crash mid-apply leaves the old base; the next tick redoes it. Rate limit: no call before reset.
  1. Tick (or Sync now)
    System: One tokio interval in the engine actor; Sync now sends the same command.
  2. Conditional GET of main per repo
    System: If-None-Match with the stored ETag; 304 means nothing to do. Calls GET /repos/{owner}/{repo}/commits/{default_branch}.
  3. Moved: read the tree
    System: Paths with blob shas; compared with the base in the store. Calls GET /repos/{owner}/{repo}/git/trees/{sha}.
  4. Download only changed blobs
    System: Unchanged blob shas are reused from the local blob cache. Calls GET /repos/{owner}/{repo}/git/blobs/{sha}.
  5. Plan: merge base, remote, local
    System: engine::plan is a pure function; it never touches disk or network.
  6. Apply files, record base in one transaction
    System: fs::apply writes temp files and renames; store commits the new base only after all renames.
  7. Report: N files updated
    System: The snapshot event updates the window and tray.
  8. Conditional GET of open proposals per group
    System: Same ETag rule: 304 when no proposal changed; a changed one is re-read with its reviews. Calls GET /repos/{owner}/{repo}/pulls?state=open.
  9. State: Syncing
    System: UML state machine: Group on this account.
  10. State: Turned off
    System: UML state machine: Group on this account.
  11. State: Waiting for rate limit
    System: UML state machine: Group on this account.
  12. State: Offline
    System: UML state machine: Group on this account.
  13. State: Last sync failed
    System: UML state machine: Group on this account.
  14. Also: Settings: paused
    System: state "paused".
  15. Also: Groups: all turned off
    System: state "all groups off".
  16. Also: Groups: loading
    System: state "loading groups".
  17. Also: Tray menu
    System: state "tray menu open".
  18. Also: Tray: quit
    System: state "app quit".
