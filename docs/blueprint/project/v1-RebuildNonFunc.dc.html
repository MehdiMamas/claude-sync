3Security: tokensAccess and refresh tokens live only in the OS keychain (Credential Manager, Keychain, Secret Service). Refreshed tokens are saved back; an expired sign-in deletes them and keeps the login name in state.json to show "expired". Tokens never go to logs, feedback or requests.json.crates/core/src/github.rs:230-238; app/src-tauri/src/auth.rs:39-80
4Security: scopesTwo sign-in modes. OAuth App with repo scope (default) or the GitHub App with per-repo access (state.json githubApp, next sign-in). The app refuses a public personal repo. Plugins in a group run code on every member’s machine, so the join screen warns.state.rs:19-22; group.rs:24; docs/architecture.md:29-39
5Security: relay authRelay calls carry the user GitHub token as a Bearer header; relay checks it against GitHub, caches a login 10 minutes, allows 120 calls an hour per login and 5 feedback posts an hour (429 after). Install page uses a signed session cookie from GitHub web sign-in.relay/api/*.ts; docs/architecture.md:314-352
6Crash handlingRelease profile keeps panic = unwind. Every core call from the background loop and file watcher goes through guard, which catches a panic and turns it into an error shown in the app, so one bad pass never kills the loop. The loop has a last-line catch.app/src-tauri/src/guard.rs:1-33; background.rs:2,34
7Update signingTauri updater with a minisign key pair; public key in tauri.conf.json (line 42), private key only with the maintainer and the release secret. The app asks /api/update at start and every 6 h with the user token; the update downloads in the background and installs on quit or Restart to update. macOS is Developer ID signed and notarized when secrets exist; Windows is not Authenticode signed; Linux ships .deb and AppImage. Update request carries target, arch, current version and the Bearer token, 60 s timeout. Bundles are minisign-signed with TAURI_SIGNING_PRIVATE_KEY. RELAY_URL defaults to an .invalid host, so a build without CLAUDE_SYNC_RELAY_URL has updates and feedback off (a feedback report is kept in the outbox). Sources disagree on installer signing: README.md says the installers are not code-signed or notarized; docs/releasing.md says macOS is signed when the APPLE_* secrets exist.app/src-tauri/tauri.conf.json:20-43; docs/architecture.md:354-364
8CostRelay on Vercel free tier; GitHub is the only store. No server database.docs/architecture.md:314
