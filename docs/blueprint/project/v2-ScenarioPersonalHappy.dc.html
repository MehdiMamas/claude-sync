Personal memory between my machines: happy path

Created 2026-11-26. Updated 2026-11-26.

As a person with two computers, I want to keep my own CLAUDE.md and memory in step, so that both computers act the same. Click a step to open its screen. The flow behind it.

Acceptance criteria: Nothing is pushed while the repo is public. Line-ending-only differences never push.
  1. Turn personal memory on
    System: A personal choice; it is saved in the personal repo once it exists.
  2. Find or make the private repo
    System: Look for claude-sync-personal (marker file claude-sync-personal.json); offer it if found, make it if not. Calls GET /repos/{owner}/{repo}.
  3. Use it
    System: The first pass pulls, merges and pushes.
  4. Merge by line, LF bytes
    System: engine::personal::merge keeps every line either side added; line endings never cause a push.
  5. Push one commit
    System: Commit and fast-forward main; a race retries from the new head. Calls POST /repos/{owner}/{repo}/git/commits.
  6. Other machine gets it on its tick
    System: Same conditional GET as group sync.
  7. Also: Settings: general
    System: state "default".
  8. Also: Settings: advanced
    System: state "default".
  9. Also: Settings: packs
    System: state "packs listed".
  10. Also: Settings: SSH
    System: state "ssh on".
  11. Also: Settings: remove a device
    System: state "confirm remove device".
