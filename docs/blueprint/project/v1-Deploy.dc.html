Release

  • A release is the GitHub release v on MehdiMamas/claude-sync with eight assets (Windows setup .exe and .sig, macOS .app.tar.gz, .sig and .dmg, Linux AppImage and .deb beta).
  • release.yml resolves the version from the tag and checks it against the files (lines 54-97), then builds on GitHub-hosted runners (windows-latest, macos-latest, ubuntu-22.04). Build jobs run in the environment release, which waits for the maintainer (line 105).
  • The workflow only creates or updates a draft. The relay serves published releases only, so nothing reaches users until the maintainer publishes the draft.
  • Signing: updater key (minisign) in the repository secret TAURI_SIGNING_PRIVATE_KEY; Apple certificate secrets in the environment release.
